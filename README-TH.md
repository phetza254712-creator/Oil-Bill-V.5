# Oil Bill V5 — ระบบจัดการบิลน้ำมัน

Oil Bill V5 เป็นโปรเจกต์ใหม่ แยกจาก Oil Bill V3/V4 โดยใช้ Vite + JavaScript, IndexedDB, Electron สำหรับ Windows และ Capacitor สำหรับ Android

## ความสามารถในรุ่นเริ่มต้น

- Dashboard สรุปยอดวันนี้และเดือนนี้ จำนวนบิล ปริมาณน้ำมัน และเอกสารฉบับร่าง
- เพิ่ม แก้ไข ค้นหา และยกเลิกบิล พร้อมเก็บประวัติรายการ
- นำเข้า Excel (`.xlsx`, `.xls`), CSV, JSON, PDF, ภาพ (`.png`, `.jpg`, `.jpeg`, `.webp`, `.bmp`, `.tif`, `.tiff`) และ Word (`.docx`)
- ตรวจจับหัวตารางไทย/อังกฤษในช่วงต้นชีต และพยายามแยกข้อมูลจากข้อความเมื่อไม่มีหัวตาราง
- OCR ภาษาไทยและอังกฤษสำหรับภาพและ PDF ที่ไม่มีชั้นข้อความ (การดาวน์โหลดโมเดลภาษาในครั้งแรกอาจต้องใช้อินเทอร์เน็ต)
- อ่าน PDF ทีละหน้า และสร้าง OCR worker เท่าที่จำเป็นเพื่อลดภาระหน่วยความจำ
- ตรวจสอบและแก้ไขข้อมูลก่อนบันทึก รองรับการเก็บรายการที่ข้อมูลไม่ครบเป็นฉบับร่างแทนการทิ้ง
- ตรวจเลขบิลซ้ำและตรวจยอดสุทธิเทียบกับยอดก่อนภาษี + VAT - ส่วนลด
- รายงานรายวัน รายเดือน และรายปี โดยไม่นับฉบับร่างหรือบิลที่ยกเลิก
- สำรอง/กู้คืน JSON และส่งออก CSV
- จัดเก็บข้อมูลภายในอุปกรณ์ด้วย IndexedDB ไม่ต้องพึ่งบัญชี Cloud
- GitHub Actions สร้าง Windows installer/portable EXE และ Android debug APK

## สิ่งที่ต้องทราบ

- OCR และการดึงข้อมูลใช้กฎ/รูปแบบข้อความภายในอุปกรณ์ ไม่ได้ใช้ AI Cloud; ผลที่อ่านได้ต้องตรวจสอบกับเอกสารจริงก่อนบันทึก
- PDF ที่เป็นภาพและภาพถ่ายอาจใช้เวลาประมวลผล โดยเฉพาะเอกสารหลายหน้า
- Word รุ่นเก่า `.doc` ยังไม่รองรับ ให้บันทึกเป็น `.docx` หรือ PDF ก่อน; OCR อาจต้องดาวน์โหลดไฟล์โมเดลภาษาในครั้งแรกที่ใช้งาน
- ข้อมูลไม่ซิงก์ข้ามเครื่องอัตโนมัติ ให้สำรอง JSON และกู้คืนบนเครื่องอื่นเมื่อย้ายอุปกรณ์
- การทดสอบ logic ไม่ได้ยืนยันความแม่นยำ OCR กับเอกสารทุกชนิด ต้องทดสอบด้วยตัวอย่างบิลจริงก่อนใช้งานทางบัญชี

## รันบนคอมพิวเตอร์

ต้องติดตั้ง Node.js 22 หรือใหม่กว่า

```bash
npm install
npm test
npm run dev
```

## สร้าง Windows EXE

```bash
npm install
npm test
npm run desktop:build
```

ไฟล์ติดตั้งและ Portable จะอยู่ใน `release/` ใช้ได้บน Windows x64 ตาม runner ที่ตั้งไว้ใน GitHub Actions

## สร้าง Android APK

ต้องติดตั้ง Android Studio, JDK 21 และ Android SDK ก่อน

```bash
npm install
npm run build
npx cap add android
npx cap sync android
npx cap open android
```

หรือ push เข้า branch `main` แล้วดาวน์โหลด artifact `Oil-Bill-V5-Android-APK` จาก GitHub Actions เมื่อ workflow สำเร็จ

## ข้อมูลสำคัญ

ฐานข้อมูล IndexedDB แยกตามแอปและอุปกรณ์ การล้างข้อมูลแอปหรือถอนการติดตั้งอาจทำให้ข้อมูลหาย ควรสำรองข้อมูลเป็นระยะ
